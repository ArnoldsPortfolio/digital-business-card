# Digital Business Card

Static single-page card (`index.html`) with a QR code (`card-qr.png` / `.svg`).

## Deploy on Vercel
1. Vercel dashboard → Add New → Project → import this repo.
2. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
3. Deploy.

If your final URL differs from what the QR encodes, regenerate the QR.
